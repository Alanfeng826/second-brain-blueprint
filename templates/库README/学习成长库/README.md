# 🎓 学习成长库

存放**系统性学习资料**。这是"成为更好的人"的弹药库，也是 `/学习` 的评估对象。

---

## 适合放入

- 教程、读书笔记、课程笔记
- 考试资料、工具使用手册
- **你自己的**方法论沉淀、能力模型、考点归纳

## 不适合放入

- **教材 / 真题原文 / 题库等外部权威知识的搬运** → 放库外 `..\_参考库\`

> 判断标准：**"这是你产出的，还是别人产出你只是搬运的？"**
> 四库装观点层（你的判断与沉淀），`_参考库` 装原料层（可查阅的外部知识）。
>
> **原因**：`/检索` `/灵感` `/关联` 是无差别跨库语义扫描。
> 实测一份备考资料可占本库 **97%** 体积（3.61 MB / 3.71 MB），
> 直接稀释信噪比 —— 问一个概念，先撞上几十道历年真题原文，而不是你自己的归纳。

---

## 命名规范

`YYYYMMDD-主题-资料类型`

例：`20260101-XX考试-论文范文-风险管理`
　　 `20260101-XX主题-课程笔记-第三章`

---

## 必打标签

详见 `..\_系统\标签体系.md`

- **状态**：`#待整理` `#已消化` `#待复盘` `#精华` `#过期`
- **类型**：`#方法论` `#工具` `#教程` `#复盘`
- **领域**：`#<考试科目>` `#<技能方向>` `#<长期方向>`
- **优先级**：`#P0核心` `#P1重要` `#P2参考`

## 目录结构

| 目录 / 文件 | 放什么 | 参与检索 / 灵感 |
|:---|:---|:---|
| `<主题>/` | **提炼层**：归纳、考点地图、备考攻略、资料索引 | ✅ |
| `YYYYMMDD-每日灵感-*.md` | 每日灵感卡片（打 `#精华` 者进灵感燃料池） | ✅ |
| `YYYYMMDD-知识库健康周报.md` | 每周知识库复盘 | ✅ |
| `README.md` | 本文件 | — |

> **提炼层留在四库，原料层放 `_参考库`。** 一个主题会同时横跨两个物理位置，这是设计而不是冗余：
> 提炼层喂给语义检索，原料层只在需要时显式查阅。

---

## 入库方式

- 资料上传后 `/入库`
- 发现盲区后用 `/学习` 制定学习路径
- 定期用 `/复盘` 检查"学到了什么 vs 存了什么"
