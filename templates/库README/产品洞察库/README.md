# 💡 产品洞察库

存放**你的思考 + 外部输入**。这是"想法和信号"的聚集地，也是 `/灵感` 的主要燃料。

---

## 适合放入

- 个人感悟、方法论随笔
- 竞品分析、行业报告、精选文章
- 用户访谈、数据案例
- 趋势判断、观点摘录

## 不适合放入

- **针对具体项目的交付物** → 放 `..\工作项目库\<项目名>\`
- **教材 / 真题 / 标准原文等外部权威知识的搬运** → 放库外 `..\_参考库\`
- **可复用的模板与清单** → 放 `..\素材模板库\`

> 判断标准：**"这是我产出的判断，还是别人产出我只是搬运的？"**
> 前者进本库，后者进 `_参考库`。

---

## 命名规范

`YYYYMMDD-来源-主题`

例：`20260101-随笔-为什么B端SaaS难做第二增长曲线`
　　 `20260101-竞品分析-某产品定价策略拆解`

---

## 必打标签

详见 `..\_系统\标签体系.md`

- **状态**：`#待整理` `#已消化` `#精华` `#过期`
- **类型**：`#竞品分析` `#方法论` `#趋势` `#数据` `#随笔`
- **领域**：`#<你的领域标签>`
- **优先级**：`#P0核心` `#P1重要` `#P2参考`

---

## 目录结构

| 文件 / 目录 | 放什么 | 参与检索 / 灵感 |
|:---|:---|:---|
| `YYYYMMDD-来源-主题.md` | 思考、分析、摘录 | ✅ |
| `README.md` | 本文件，库的边界声明 | — |

> 本库通常平铺即可，不要建太多子目录 —— 子目录会削弱跨主题关联。

---

## 入库方式

- **网页 / 文章链接** → 对 Agent 说"收藏这篇文章"，自动抓正文 → 生成入库报告 → 存入本库
- **自己的思考** → 直接粘贴后 `/入库`
- **标记 `#精华`** 的文档会被"每日灵感"自动抽取

---

## ⚠️ 关于精华池

本库是精华池的**主要来源**。原因：`/灵感` 应该建立在**你的判断**之上，而不是教材目录之上。

- 精华池目标规模：**5–8 篇**（太少会让灵感推送反复 fallback，太多会失去筛选意义）
- **不要**给原料层（`_参考库`）的提炼笔记批量打 `#精华` —— 会反向污染灵感池
