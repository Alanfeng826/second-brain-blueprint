# 📦 参考库（库外）

> 位置：`<你的知识库>\ _参考库`
> 定位：**原料层** —— 外部权威知识的搬运，不是你产出的知识。

---

## 与四库的关系

| 层 | 装什么 | 参与 `/检索` `/灵感` `/关联` |
|:---|:---|:---|
| 四库（工作项目库 / 产品洞察库 / 学习成长库 / 素材模板库） | **观点层**：你产出的判断、方案、灵感、复盘 | ✅ 是 |
| `_参考库`（本目录） | **原料层**：教材、真题、标准原文、行业报告 | ❌ 默认否 |
| `归档` | **历史层**：AI 中间产物、过期文件 | ❌ |

---

## 为什么放在四库之外

`/检索` `/灵感` `/关联` 是**无差别跨库语义扫描**。外部原料有两个特征：

1. **体量大** —— 实测：单份备考资料 3.61 MB，占所属库 **97%** 体积（3.61 / 3.71 MB）
2. **非你产出** —— 检索它 ≈ 翻教材；检索四库 = 复用你自己的判断

两者混在同一目录树，会直接稀释四库的信噪比
（问一个概念，先撞上几十道历年真题原文，而不是你自己的方法论笔记）。
所以物理隔离，需要时显式来取。

## 目录约定

```text
_参考库/
└── <主题>/
    ├── 原始数据 / 题库（*.json / *.tsv）
    ├── 大体积查阅型 HTML 工具页 / 离线参考
    └── 原文 / 教材 / 标准
```

对应的**提炼层**留在四库（如 `学习成长库\<主题>\`）。

> **分界口诀**：*"能否被 `/检索` 有效利用？"*
> HTML / JSON 基本是噪声（人看可以，语义检索用不上）；Markdown 提炼笔记才是资产。

---

## 怎么用

- **查阅原文 / 刷题** → 浏览器直接打开本目录下的文件，离线可用
- **查提炼结论** → 去四库对应的主题目录
- **让 Agent 用原料内容** → 默认只扫四库；需要时明确说"也查一下 `_参考库`"

---

## ⚠️ 两条硬规则

1. **本目录内容不参与"每日灵感"抽取。** 精华池只从四库的观点层取。
2. **不要给本目录的提炼笔记批量打 `#精华`** —— 会反向污染灵感池。

---

## 什么不该放进这里

- **你自己的判断与归纳** → 那是观点层，回四库
- **AI 作业的中间产物** → 那是历史层，去 `归档`
