# ✅ 知识库落地上手清单

> 分阶段路线。每周的验收标准是"**在真实工作上用过一次**"，不是"知道有这个功能"。

---

## 第 0 步：搭骨架（半天）

- [ ] 建立 4 库文件夹 + `_系统` 元目录
- [ ] 抄 `_系统/` 下的四份系统文档，**把占位符全部替换成本人背景**
- [ ] 抄四份库 README，写清每库的"适合放入 / **不适合放入**"
- [ ] 配置全局提示词（写入工作区记忆文件，或 Agent 全局设置）
- [ ] 确定工作项目库的「文档类型标签」取值集合（生成器检索主键）
- [ ] 把 12 条指令做成可调用的 Skill
- [ ] 配置 2 个自动化（每周复盘 / 每日灵感）

> ⚠️ 不要在这一步迁移历史文件。**先让新东西按新规则进来。**

---

## 第 1 周：跑通入库与检索

- [ ] 把最近 10 篇文档丢进对应库，用 `/入库` 标准化
- [ ] 用 `/检索` 跨库查一个你常问的问题，验证效果
- [ ] 检查：标签是不是都打上了？有没有打错库的？

**验收**：你能不看目录，靠 `/检索` 找到三周前的一份文档。

---

## 第 2 周：用起来写与连

- [ ] 用 `/写作` 基于知识库写一份**真实交付物**（不要用测试数据）
- [ ] 用 `/关联` 对一篇核心文档建立连接

**验收**：写出的东西里，至少有一处引用是你自己过去的判断，而不是通用知识。

---

## 第 3 周：项目与复盘习惯

- [ ] 用 `/项目` 对一个在跑项目生成知识地图
- [ ] 周日看自动化推送的复盘报告

**验收**：复盘报告里指出的"待整理积压"，你确实去处理了。

---

## 第 4 周：补齐闭环

- [ ] `/灵感` `/学习` `/标签` `/输出` 各试一次
- [ ] 收藏 3 篇好文章（"收藏这篇文章"）
- [ ] 上传 1 段会议记录（"整理会议"）

**验收**：灵感推送里出现的是你自己文档里的内容，不是 fallback 提示。

---

## 持续动作

| 频率 | 动作 |
|:---|:---|
| 每周日 | 看 `/复盘` 报告，处理 `#待整理` 积压 |
| 每月 | 跑一次 `/标签` 治理（同义合并、废弃低频标签） |
| 每 1–2 月 | 跑一次 `/分层治理`（体积诊断 → 分层 → 归档 → 精华池 → 文档同步） |
| 每季度 | 回看一次本清单，检查有没有哪一步退化了 |

---
